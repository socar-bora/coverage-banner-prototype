# 차종 리스트 · 보장상품 배너 상태값 프로토타입

쏘카 웹 예약 차종 리스트 화면의 보장상품 배너 상태값을 피그마 시안 그대로 구현한 인터랙티브 프로토타입입니다.

- 열어보기: https://socar-bora.github.io/coverage-banner-prototype/
- 피그마 원본: https://www.figma.com/design/qx25HScQEfYlTPslaZTsLP/?node-id=13103-167588
- index.html 한 파일로 동작합니다. 이미지·아이콘·폰트가 모두 내장되어 있어 외부 의존성이 없습니다.

## 상태값

- 지역: 내륙 / 제주
- 지난 예약 보장상품: 완전보장 / 실속보장 — 제주는 완전면책으로 고정
- 배너: 최초 진입 시 펼침 / 한 번 본 뒤 닫힘

## 인터랙션

- 배너 ∧ 접기, 닫힌 배너를 탭하면 다시 펼침
- 실속보장 → 완전보장 바꾸기, 실속보장으로 되돌리기
- 블랙라벨 차종의 특약 적용 ⓘ → 자차손해담보 특약 안내 바텀시트

## 업데이트

피그마가 바뀌면 index.html을 새 버전으로 교체해 커밋하면 됩니다.
