# 차종 리스트 · 혜택 배너 상태값 프로토타입

쏘카 웹 예약(SEO/AEO) 차종 리스트 화면의 보장상품(혜택) 배너 상태값을
피그마 시안("10.23 피드백 반영" 섹션) 그대로 구현한 인터랙티브 프로토타입입니다.

- `index.html` 한 파일로 동작합니다 (이미지·아이콘·폰트 모두 내장, 외부 의존성 없음).
- 상태값: 지역(내륙/제주) × 지난 예약 보장상품(완전보장 기본값/실속보장) × 바텀시트(열림/닫힘 450px) × 진입(최초 진입/한 번 봤음)
- 배너: "혜택까지 포함된 가격이에요" — 보장상품(완전보장·실속보장·제주 완전면책) · 10% 적립 · 주행요금 혜택 3단 아이콘, 한 번 본 뒤에는 44px 한 줄 요약으로 접힘
- 인터랙션: 배너 접기/펼치기, 바텀시트 핸들 열기/닫기, 블랙라벨 **특약 적용 ⓘ** 바텀시트, As-Is(현재 앱) 비교 보기
- 피그마 원본: https://www.figma.com/design/qx25HScQEfYlTPslaZTsLP/?node-id=13325-135246

## GitHub Pages로 보기

저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `/ (root)`** 로 저장하면
`https://<계정>.github.io/<저장소 이름>/` 에서 열립니다. (비공개 저장소의 Pages는 유료 플랜에서만 지원)

## 업데이트

피그마가 바뀌면 `index.html`을 새 버전으로 교체하고 커밋하면 됩니다.
