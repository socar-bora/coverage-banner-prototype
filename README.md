# 차종 리스트 · 보장영역 배너 상태값 프로토타입

쏘카 웹 예약(SEO/AEO) 차종 리스트 화면의 보장영역(보장상품·혜택) 배너 상태값을
피그마 최종 정리 섹션("쏘카앱-가지러가기, 배달, 즉시배달") 그대로 구현한 인터랙티브 프로토타입입니다.

- `index.html` 한 파일로 동작합니다 (이미지·아이콘·폰트 모두 내장, 외부 의존성 없음).
- 화면: 가지러 가기 / 여기로 배달받기 / 지금 배달받기(즉시배달)
- 케이스: 부름 호출존(가지러 가기) · 블랙라벨 탭(여기로 배달받기, 논의 중)
- 상태값: 지역(내륙/제주) × 지난 예약 보장상품(완전보장 기본값/실속보장) × 바텀시트(축소 450px 기본 · 펼침 — 세 화면 모두 축소로 진입) × 진입(최초 진입/한 번 봤음) × 문구(기본/긴 문구 줄바꿈 확인)
- 배너: "보장은 포함, 혜택은 추가로 받아요" — 보장상품 강조 칸(완전보장·실속보장·제주 완전면책) + 주행요금·적립 2줄. 미확인 유저에게만 1회 자동 펼침, 그 뒤에는 58px 2줄 요약으로 접힘
- 1회 확인 유저: ① 바텀시트를 확장해 차량 리스트를 1회 이상 확인한 유저 ② 배너를 클릭/누른 유저 (패널의 **다시 진입** 버튼으로 재진입 시 동작 확인)
- 인터랙션: 배너 접기/펼치기, 바텀시트 핸들 펼침/축소, 블랙라벨 **특약 적용 ⓘ** 바텀시트, As-Is(현재 앱) 비교 보기
- 피그마 원본: https://www.figma.com/design/qx25HScQEfYlTPslaZTsLP/?node-id=13374-144145

## GitHub Pages로 보기

저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `/ (root)`** 로 저장하면
`https://<계정>.github.io/<저장소 이름>/` 에서 열립니다. (비공개 저장소의 Pages는 유료 플랜에서만 지원)

## 업데이트

피그마가 바뀌면 `index.html`을 새 버전으로 교체하고 커밋하면 됩니다.
