특약 바텀시트피그마 노드 ↗

    변경 방향 · As-Is → To-Be

    • 1총결제요금 안내 띠 → 보장상품 안내 배너. 유저가 고른 보장상품(완전보장·실속보장·제주 완전면책)의 혜택을 배너 안에 담아 보여주고, 한 번 본 뒤에는 한 줄 요약으로 접혀요. 실속보장이면 완전보장으로 바꾸는 업셀, 블랙라벨은 특약 안내가 같은 자리에서 처리돼요.
    • 2차종마다 붙던 '총결제요금' 태그 삭제. 배너(공통 영역)에서 한 번만 안내하고, 행에는 10%적립 태그와 보장상품 태그만 남아요.
    • 3'차 상세 보기' 화살표(›) 삭제. 행 전체가 차종 선택이 되고, 상세는 다음 단계에서 봐요.
    • 4썸네일 아래 주행요금 안내(0~NNN원/km) 삭제. 주행요금 혜택은 배너 문구("주행요금 혜택 포함가")로 흡수되고, '주행요금 무료' 태그만 남아요.
    • 5제주에도 10%적립 태그 추가. 제주 행은 연식·차급·인승 태그 아래에 10%적립 → 정가·할인가 → 완전면책 순서로 바뀌어요.

    피그마 메모 (AsIs 섹션) 총 결제요금 안내 배너 → 배너 내, 유저 선택 값에 따른 보험 정보 포함하여 노출 총 결제 요금 태그 삭제 → 공통 영역 내 포함으로 변경 차 상세 보기, 주행요금 안내 표기 삭제
